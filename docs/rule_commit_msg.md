| Từ khóa    | Ý nghĩa                          | Ví dụ                         |
| :--------- | :------------------------------- | :---------------------------- |
| `feat`     | Tính năng mới (Feature)          | `feat: add google login`      |
| `fix`      | Sửa lỗi (Bug fix)                | `fix: crash on iphone 14`     |
| `chore`    | Việc vặt (không đổi code chính)  | `chore: update packages`      |
| `docs`     | Tài liệu                         | `docs: update readme`         |
| `style`    | Chỉnh sửa style (spaces, format) | `style: format code`          |
| `refactor` | Sửa code (không thêm tính năng)  | `refactor: optimize loop`     |
| `test`     | Thêm test case                   | `test: add unit test for api` |
