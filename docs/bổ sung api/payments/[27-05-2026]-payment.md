# Tài liệu Đề xuất API — Cập nhật Danh sách Phương thức thanh toán (QR & Card Portable)

> Phiên bản đề xuất: 1.8.2 · Cập nhật: 2026-05-27  
> API chỉnh sửa: `GET /v1/payment-methods`

---

## 1. Lý do & Mục tiêu

Để nâng cao khả năng cấu hình động từ máy chủ, tránh hardcode các thông tin nhạy cảm ở phía client (máy POS), tài liệu này đề xuất bổ sung cấu hình trực tiếp vào danh sách phương thức thanh toán:

1. **VietQR (`qr_bidv`)**: Cấu hình tài khoản ngân hàng thụ hưởng thụ động (`bankConfig`) để tự động tạo VietQR động trên máy POS (Mục 7.4).
2. **Card Portable (`card_bidv`)**: Cấu hình kết nối trực tiếp đến thiết bị đầu cuối ngân hàng di động Ingenico (`terminalConfig`) thay vì hardcode trong service cục bộ.

---

## 2. Chi tiết thay đổi API

### 2.1 Thay đổi response của `GET /v1/payment-methods`

Bổ sung trường `bankConfig` (nullable) và `terminalConfig` (nullable) bên trong mỗi phương thức thanh toán tương ứng.

- **Endpoint:** `GET /v1/payment-methods`
- **Xác thực:** Yêu cầu header `Authorization: Bearer <accessToken>`.

#### **Mô tả cấu trúc trường `bankConfig` (Dành cho QR):**

| Trường        | Kiểu dữ liệu | Bắt buộc | Mô tả                                                           |
| :------------ | :----------- | :------- | :-------------------------------------------------------------- |
| `bankCode`    | string       | ✓        | Mã ngân hàng tiêu chuẩn VietQR (Ví dụ: `BIDV`, `VCB`, `ICB`...) |
| `accountNo`   | string       | ✓        | Số tài khoản ngân hàng thụ hưởng nhận tiền                      |
| `accountName` | string       | ✓        | Tên chủ tài khoản thụ hưởng (In hoa không dấu)                  |

#### **Mô tả cấu trúc trường `terminalConfig` (Dành cho Card Portable):**

| Trường         | Kiểu dữ liệu | Bắt buộc | Mô tả                                                                |
| :------------- | :----------- | :------- | :------------------------------------------------------------------- |
| `posUrl`       | string       | ✓        | URL cổng kết nối socket trực tiếp tới thiết bị POS Ingenico Sandbox  |
| `merchantName` | string       | ✓        | Tên đơn vị chấp nhận thẻ (Merchant Name)                             |
| `cashierId`    | string       | ✓        | Định danh thu ngân (Cashier ID)                                      |
| `license`      | string       | ✓        | Chuỗi giấy phép (License Key) được BIDV cung cấp để kết nối thiết bị |

## 3. Hướng dẫn tích hợp phía Front-end

### 3.1 Luồng thanh toán QR:

1. Khi khởi chạy app hoặc đăng nhập thành công, máy POS gọi `GET /v1/payment-methods`.
2. Trích xuất thuộc tính `bankConfig` từ cổng `qr_bidv` gán vào `AppContext.tenantConfig`.
3. Khi gọi API sinh mã QR (`POST /v1/payments/{id}/qr`), truyền các giá trị này lên.

### 3.2 Luồng thanh toán Card Portable:

1. Khi thu ngân chọn cổng thanh toán Thẻ di động (`card_bidv`), máy POS đọc cấu hình `terminalConfig` của `card_bidv`.
2. Truyền động các tham số `posUrl`, `merchantName`, `cashierId`, `license` vào hàm `connect()` của `PortablePaymentService` thay vì sử dụng các biến hằng số hardcode cục bộ.
