# Yêu cầu bổ sung API Kiểm tra Voucher POS (Voucher Verification)

Tài liệu này mô tả chi tiết yêu cầu thiết kế API kiểm tra tính hợp lệ và lấy cấu hình giảm giá của Voucher từ Server phục vụ cho máy POS. Voucher này mặc định giảm giá theo phần trăm (%). Client (POS) sẽ tự tính toán giá trị chiết khấu thực tế dựa trên giỏ hàng local.

---

## 📌 Endpoint đề xuất bổ sung:

- **Tên API:** Xác thực & Kiểm tra Voucher
- **Endpoint:** `POST /v1/pos/vouchers/verify`
- **Mô tả:** Gửi duy nhất mã voucher lên qua Request Body, Server kiểm tra và trả về cấu hình chi tiết của voucher (phần trăm giảm, mức tối đa và danh sách biến thể sản phẩm được áp dụng) nếu mã đó tồn tại và đang hoạt động.

---

## 📥 Cấu trúc Request Body (`POST /v1/pos/vouchers/verify`)

```json
{
  "code": "KM20"
}
```

### 📋 Mô tả chi tiết các trường Request:

| Tên trường | Kiểu dữ liệu | Bắt buộc | Ví dụ giá trị | Mô tả                                                                       |
| :--------- | :----------- | :------: | :------------ | :-------------------------------------------------------------------------- |
| **`code`** | `string`     |    ✓     | `"KM20"`      | Mã voucher khách hàng yêu cầu áp dụng (Không phân biệt chữ hoa/chữ thường). |

---

## 📤 Cấu trúc Response Body (200 OK)

Khi Voucher hợp lệ và thỏa mãn mọi điều kiện áp dụng:

```json
{
  "code": "KM20",
  "percent": 20,
  "maxDiscountAmount": 50000,
  "applicableVariantIds": [
    "019e437b-1620-71c0-9924-c1df81683181",
    "019e437b-1620-71c0-9924-c1df81683182"
  ]
}
```

### 📋 Mô tả chi tiết các trường Response:

| Tên trường                 | Kiểu dữ liệu | Bắt buộc | Ví dụ giá trị   | Mô tả                                                                                                                                                |
| :------------------------- | :----------- | :------: | :-------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`code`**                 | `string`     |    ✓     | `"KM20"`        | Mã voucher xác nhận lại đã được chuẩn hóa.                                                                                                           |
| **`percent`**              | `number`     |    ✓     | `20`            | Phần trăm giảm giá (Từ `0` đến `100`).                                                                                                               |
| **`maxDiscountAmount`**    | `number`     |          | `50000`         | Số tiền giảm tối đa cho phép (VND). Nếu không trả về nghĩa là không giới hạn mức giảm tối đa.                                                        |
| **`applicableVariantIds`** | `string[]`   |          | `["019e43..."]` | Danh sách ID biến thể sản phẩm (Variant IDs) được áp dụng voucher này.<br>• **Mảng rỗng `[]` hoặc null**: Mặc định áp dụng cho **toàn bộ sản phẩm**. |

---

## ❌ Các mã lỗi đặc thù nghiệp vụ (Business Errors - 400 Bad Request)

Trường hợp mã Voucher không hợp lệ, hết hạn hoặc không áp dụng được, API trả về mã lỗi HTTP `400` theo chuẩn định dạng lỗi của POS:

```json
{
  "error": "pos.voucher_invalid",
  "message": "Mã giảm giá không hợp lệ hoặc đã hết hạn."
}
```

### 📋 Bảng danh mục lỗi Voucher đề xuất:

| `error` (Mã lỗi)          | `message` (Thông báo gợi ý)                   | Nguyên nhân lỗi                                                  |
| :------------------------ | :-------------------------------------------- | :--------------------------------------------------------------- |
| **`pos.voucher_invalid`** | `"Mã giảm giá không hợp lệ hoặc đã hết hạn."` | Mã không tồn tại, đã hết hạn, chưa kích hoạt hoặc hết lượt dùng. |
