# Bổ sung API: Lấy Danh sách Đơn hàng (Lịch sử)

Tài liệu này bổ sung endpoint lấy danh sách đơn hàng cho máy POS (phục vụ tab **Quản lý Đơn hàng**).

---

## 1. Lấy danh sách đơn hàng (Lịch sử)

> **Luồng hoạt động:** Máy POS gửi request lấy danh sách đơn hàng phục vụ cho việc quản lý, tìm kiếm, lọc và phân trang lịch sử bán hàng.

- **Endpoint:** `GET /v1/pos/orders`
- **Xác thực:** Yêu cầu `Authorization: Bearer <accessToken>` (Device JWT)
- **Quyền hạn (Permission):** `pos:checkout`

### Query Parameters

| Tham số     | Kiểu dữ liệu | Bắt buộc | Mô tả                                                                              |
| ----------- | ------------ | -------- | ---------------------------------------------------------------------------------- |
| `status`    | string       | Không    | Lọc theo trạng thái đơn hàng: `PENDING`, `COMPLETED`, `REFUNDED`, `FAILED`         |
| `q`         | string       | Không    | Tìm kiếm nâng cao: Theo **Mã đơn hàng (Order ID)**, hoặc **SKU/Tên sản phẩm**      |
| `date_from` | string       | Không    | Lọc từ ngày (Định dạng ISO 8601, ví dụ: `2026-05-19T00:00:00Z` hoặc `2026-05-19`)  |
| `date_to`   | string       | Không    | Lọc đến ngày (Định dạng ISO 8601, ví dụ: `2026-05-19T23:59:59Z` hoặc `2026-05-19`) |
| `page`      | integer      | Không    | Số trang cần lấy (Bắt đầu từ 1, mặc định: 1)                                       |
| `limit`     | integer      | Không    | Số lượng bản ghi mỗi trang (Mặc định: 20, tối đa: 100)                             |

### Các lỗi thường gặp (Error Response)

| HTTP Code | Error Code              | Ý nghĩa / Hướng xử lý                                  |
| --------- | ----------------------- | ------------------------------------------------------ |
| `400`     | `pos.invalid_params`    | Tham số query không hợp lệ (ví dụ: định dạng ngày sai) |
| `401`     | `auth.unauthorized`     | Token hết hạn hoặc không hợp lệ                        |
| `403`     | `auth.forbidden`        | Không có quyền `pos:checkout`                          |
| `500`     | `server.internal_error` | Lỗi máy chủ                                            |
