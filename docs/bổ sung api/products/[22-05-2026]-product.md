# Yêu cầu bổ sung trường thông tin & API sản phẩm POS (Search & Sync Pull)

Tài liệu này mô tả chi tiết các trường thông tin cần bổ sung và thiết kế của API phục vụ cho luồng đồng bộ sản phẩm từ Server về cơ sở dữ liệu Local (SQLite/WatermelonDB).

---

## 📌 Các Endpoint đề xuất bổ sung & cập nhật:

1. **Tìm kiếm sản phẩm theo từ khoá (Online):** `GET /v1/pos/search`
2. **Tra cứu sản phẩm theo Barcode/SKU (Online):** `GET /v1/pos/lookup`
3. **[NEW] API Đồng bộ sản phẩm (Pull Products to Local):** `GET /v1/pos/products/sync`

---

## 🔍 Phần 1: Cập nhật API Tìm kiếm & Tra cứu Online (`GET /v1/pos/search` & `GET /v1/pos/lookup`)

Để máy POS tính toán chính xác tiền thuế (VAT) và kiểm tra đúng trạng thái hoạt động của sản phẩm ngay tại thời điểm bán, đối tượng trả về (`PosLookupResult`) cần bổ sung thêm **2 trường** sau:

### 📋 Các trường cần bổ sung:

| Tên trường     | Kiểu dữ liệu | Bắt buộc | Ví dụ giá trị | Mô tả & Ý nghĩa                                                                                                                                                                                            |
| :------------- | :----------- | :------: | :------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`taxRate`**  | `number`     |    ✓     | `8`           | Thuế suất áp dụng cho sản phẩm này (dạng số nguyên % dạng chẵn).<br>• `8` (8% VAT)<br>• `10` (10% VAT)<br>• `0` (Không chịu thuế).<br>_(Giúp POS tính đúng tiền thuế GTGT dòng hàng trước khi thanh toán)_ |
| **`isActive`** | `boolean`    |    ✓     | `true`        | Trạng thái hoạt động của biến thể.<br>• `true`: Đang kinh doanh.<br>• `false`: Đã ngừng bán.<br>_(POS sẽ tự động bỏ qua/không hiển thị sản phẩm nếu `isActive = false`)_                                   |

### 📝 Cấu trúc Response mẫu mong muốn (`PosLookupResult`):

```json
{
  "variantId": "019e437b-1620-71c0-9924-c1df81683181",
  "productId": "019e437b-1620-71c0-9924-c1df81683182",
  "sku": "SP-001-XL",
  "productName": "Áo thun",
  "variantName": "XL / Đen",
  "unitId": "019e437b-1620-71c0-9924-c1df81683183",
  "unitCode": "CAI",
  "price": 150000,
  "onHand": 50,
  "reserved": 5,
  "available": 45,
  "trackBatches": false,
  "trackSerials": false,
  "barcode": "8934567890123",

  // === 🚀 2 TRƯỜNG BỔ SUNG MỚI ===
  "taxRate": 8,
  "isActive": true
}
```

## 🔄 Phần 2: API Đồng bộ sản phẩm từ Server về Local SQLite (`GET /v1/pos/products/sync`)

Để phục vụ luồng **Đồng bộ sản phẩm ngoại tuyến**, POS cần tải hàng loạt sản phẩm về máy lưu vào SQLite. API này cần được tối ưu cho việc đọc nhanh và đồng bộ delta (chỉ lấy thay đổi mới nhất).

### 📋 Tham số Request (Query Parameters):

| Tham số            | Kiểu dữ liệu            | Bắt buộc | Mặc định | Mô tả                                                                                                                                                                                   |
| :----------------- | :---------------------- | :------: | :------: | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`lastSyncedAt`** | `number` (Timestamp ms) |          |          | Mốc thời gian lần đồng bộ cuối cùng của client.<br>• Nếu truyền: Chỉ trả về sản phẩm được thêm/sửa/xóa sau mốc này (Sync Delta).<br>• Nếu bỏ trống: Tải lại toàn bộ từ đầu (Full Sync). |
| **`page`**         | `number`                |          |   `0`    | Chỉ mục trang cần lấy (bắt đầu từ 0).                                                                                                                                                   |
| **`limit`**        | `number`                |          |  `100`   | Số lượng bản ghi trên một trang (Tối đa: 500).                                                                                                                                          |

### 📋 Cấu trúc đối tượng sản phẩm trả về (Khớp 100% với Local DB dưới client):

| Tên trường      | Kiểu dữ liệu            | Bắt buộc | Ví dụ giá trị          | Mô tả                                                             |
| :-------------- | :---------------------- | :------: | :--------------------- | :---------------------------------------------------------------- |
| **`id`**        | `string (uuid)`         |    ✓     | `"019e43..."`          | ID biến thể sản phẩm (Variant ID).                                |
| **`productId`** | `string (uuid)`         |    ✓     | `"019e43..."`          | ID sản phẩm cha.                                                  |
| **`sku`**       | `string`                |    ✓     | `"SP-001-XL"`          | Mã SKU của biến thể.                                              |
| **`barcode`**   | `string`                |          | `"893456789"`          | Mã vạch để quét sản phẩm offline.                                 |
| **`name`**      | `string`                |    ✓     | `"Áo thun - Đen / XL"` | Tên hoàn chỉnh hiển thị ở POS (tên sản phẩm + tên biến thể).      |
| **`price`**     | `number`                |    ✓     | `150000`               | Giá bán của sản phẩm.                                             |
| **`taxRate`**   | `number`                |    ✓     | `8`                    | Thuế suất áp dụng (8, 10, 0...).                                  |
| **`stock`**     | `number`                |    ✓     | `45`                   | Số lượng tồn kho khả dụng tại thời điểm đồng bộ.                  |
| **`unitId`**    | `string (uuid)`         |    ✓     | `"019e43..."`          | ID đơn vị tính.                                                   |
| **`unitCode`**  | `string`                |    ✓     | `"CAI"`                | Mã đơn vị tính (Cái, Chai, Hộp...).                               |
| **`isActive`**  | `boolean`               |    ✓     | `true`                 | Trạng thái hoạt động.                                             |
| **`isDeleted`** | `boolean`               |    ✓     | `false`                | Đánh dấu xóa mềm. Dùng để client SQLite xóa/ẩn bản ghi tương ứng. |
| **`updatedAt`** | `number` (Timestamp ms) |    ✓     | `1779416787530`        | Thời điểm cập nhật cuối trên server.                              |
