### Endpoint: Lấy danh sách đơn hàng có phân trang

Sử dụng để xem lịch sử đơn hàng từ xa (Remote-First).

- **Method**: `GET`
- **Path**: `/api/v1/orders`

#### 1. Query Parameters

| Tham số        | Kiểu dữ liệu | Bắt buộc | Mô tả                                                    |
| :------------- | :----------- | :------: | :------------------------------------------------------- |
| `page`         | number       |  Không   | Số trang (mặc định: 1)                                   |
| `limit`        | number       |  Không   | Số bản ghi/trang (mặc định: 20)                          |
| `status`       | string       |  Không   | Lọc theo trạng thái (`COMPLETED`, `PENDING`, `REFUNDED`) |
| `search_query` | string       |  Không   | Tìm kiếm theo ID đơn hàng                                |
| `date_from`    | string       |  Không   | Lọc từ ngày (ISO 8601)                                   |
| `date_to`      | string       |  Không   | Lọc đến ngày (ISO 8601)                                  |

#### 2. Response Body (IBaseResponse chuẩn)

```json
{
  "success": true,
  "status_code": 200,
  "message": "Success",
  "data": [
    {
      "id": "uuid-001",
      "shift_id": "shift-uuid",
      "staff_id": "staff-uuid",
      "total": 150000,
      "status": "COMPLETED",
      "items_snapshot": [...],
      "payments_snapshot": [...],
      "created_at": 1715764551000
    }
  ],
  "meta": {
    "total": 2000,
    "page": 1,
    "limit": 20,
    "totalPages": 100,
    "hasNextPage": true,
    "timestamp": 1715764551000
  },
  "error": null
}
```

#### 3. Chi tiết các trường trong `data`

| Trường              | Kiểu dữ liệu      | Mô tả                                                    |
| :------------------ | :---------------- | :------------------------------------------------------- |
| `id`                | string            | UUID của đơn hàng                                        |
| `shift_id`          | string            | UUID của ca làm việc                                     |
| `staff_id`          | string            | UUID của nhân viên                                       |
| `status`            | string            | Trạng thái: `PENDING`, `COMPLETED`, `REFUNDED`, `FAILED` |
| `subtotal`          | number            | Tổng tiền trước thuế/chiết khấu                          |
| `discount`          | number            | Số tiền chiết khấu tổng                                  |
| `total`             | number            | Tổng tiền cuối cùng                                      |
| `total_tax`         | number            | Tổng thuế                                                |
| `can_return`        | boolean           | **Trường bổ sung**: Cho phép trả hàng (Server tính toán) |
| `items_snapshot`    | ItemSnapshot[]    | Chi tiết sản phẩm (Xem schema gốc tại order.md)          |
| `payments_snapshot` | PaymentSnapshot[] | Chi tiết thanh toán (Xem schema gốc tại order.md)        |
| `created_at`        | number            | Unix timestamp thời điểm tạo đơn                         |

#### 4. Chi tiết các trường Metadata (`meta`)

| Trường        | Kiểu dữ liệu | Mô tả                                               |
| :------------ | :----------- | :-------------------------------------------------- |
| `total`       | number       | Tổng số bản ghi thỏa mãn điều kiện lọc              |
| `page`        | number       | Trang hiện tại                                      |
| `limit`       | number       | Số bản ghi trên mỗi trang                           |
| `totalPages`  | number       | Tổng số trang (`ceil(total / limit)`)               |
| `hasNextPage` | boolean      | Trạng thái có còn trang tiếp theo hay không         |
| `timestamp`   | number       | Thời điểm server trả về dữ liệu (Unix timestamp ms) |

---

> **Ghi chú cho Frontend**: Dữ liệu từ API này hiển thị trực tiếp (Remote-First), không lưu xuống database local.
